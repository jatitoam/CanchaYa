# CanchaYa

CanchaYa is an MVP that helps amateur football organizers quickly find and reserve available soccer fields for Saturday matches. Instead of calling or messaging multiple venues, users can browse a list of available fields, compare their basic information, and reserve an open time slot with a single tap. Field owners can also publish and manage their Saturday availability through a simple interface.

## The Musts

- Display a list of available football fields.
- Show open Saturday time slots.
- Display field information:
  - Neighbourhood
  - Surface
  - Field size
  - Hourly price
- Allow one-tap reservation.
- Provide a basic interface for field owners to manage Saturday availability.
- Enable users to complete a reservation in under one minute.
- Keep availability synchronized so organizers only see current open slots.

## Success Criteria

- Users can reserve a field in under one minute.
- At least 80% of reservation attempts complete successfully without manual intervention.
- Field owners regularly update their available Saturday slots.
- Early users successfully book matches and report that the experience is easy and intuitive.
